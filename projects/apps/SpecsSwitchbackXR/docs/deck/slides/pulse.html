The first view. The Rhythm 24 talks the standard heart-rate profile, so the lens reads it directly. The Pulse panel shows bpm, the zone and session time. The lens then forwards each reading to goggl1 so the goggle’s own Pulse screen stays in step, and it sets the goggle’s clock from the glasses when they connect — goggl1 has no real-time clock of its own.
