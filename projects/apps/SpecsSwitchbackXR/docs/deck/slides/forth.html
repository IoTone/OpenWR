How it was built

The devices are Forth prompts. The lens just types.

Both boards run ESPIDFORTH, with the prompt over a Bluetooth serial link. A new feature is often one new word, tried live before it’s flashed.

This is what made three days possible. goggl1 and the maplet both run ESPIDFORTH, our Forth for ESP-IDF, and the prompt is exposed over Bluetooth. The lens doesn’t need a protocol — it sends lines of Forth and reads the replies. When a feature needed something new on a device, like setting the goggle’s clock or sending photos as base64, it was one new word. We could try it live at the prompt, then flash it. The clock! example is illustrative.
