The glasses sit in the middle. The strap streams heart rate straight to the lens. goggl1 and the maplet each expose a Nordic UART serial service, which is really a Forth prompt — the lens just types commands. All three links run at the same time through one scan queue. The phone link is the next step; today the pin board walks a demo route.
